# 省略 if

> [!info] 出自 [[01 错综时间条件句与省略 if 的倒装]]

## 一句话定义

虚拟条件句中可去掉 if，借助 had、were、should 的前置构成倒装，句首不再保留 if。

## 讲解

虚拟条件句省略 if 时，把从句中的 had、were 或 should 提到主语前面，句子构成部分倒装。

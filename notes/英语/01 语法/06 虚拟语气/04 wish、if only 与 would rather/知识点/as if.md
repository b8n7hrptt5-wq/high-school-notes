# as if

> [!info] 出自 [[01 wish、if only 与 would rather 的虚拟]]

## 一句话定义

引导方式状语从句，表示“好像”；所述内容与事实相反时从句用虚拟语气。

## 讲解

as if、as though 从句同样按事实相反与否处理：He talks as if he knew everything.（他说得好像什么都懂。）

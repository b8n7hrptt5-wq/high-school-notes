# must have done

> [!info] 出自 [[01 情态动词 + have done 的推测与评价]]

## 一句话定义

对过去事情的肯定推测，意为“过去一定做过某事”。

## 讲解

must have done 肯定过去一定做过；can’t have done 否定过去不可能做过。

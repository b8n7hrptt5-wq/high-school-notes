# a b c 关系

> [!info] 出自 [[01 椭圆及其标准方程与几何性质]]

## 一句话定义

$c^2=a^2-b^2$，$a>b>0$。

## 讲解

a b c 关系为 $c^2=a^2-b^2$，$a$ 对应长半轴、$b$ 对应短半轴、$c$ 对应半焦距。[[离心率]] $e=\frac{c}{a}$，范围 $0<e<1$；$e$ 越接近 0 椭圆越接近圆，$e$ 越接近 1 椭圆越扁。

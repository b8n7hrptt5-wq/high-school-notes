# needn’t have done

> [!info] 出自 [[01 情态动词 + have done 的推测与评价]]

## 一句话定义

意为“本不必做某事却做了”，说明动作已发生但没有必要。

## 讲解

needn’t have done 常表示做了但没必要。could have done 可以表示本有机会却没做，也可以表示过去可能做过，要结合语境。

# if only

> [!info] 出自 [[01 wish、if only 与 would rather 的虚拟]]

## 一句话定义

表示“要是……就好了”的虚拟结构，用法与 wish 从句相同，语气更强，句末常用感叹号。

## 讲解

if only 与 wish 从句形式相同，表达强烈愿望，可单独成句。

# should have done

> [!info] 出自 [[01 情态动词 + have done 的推测与评价]]

## 一句话定义

对过去的评价，意为“本应该做某事却没做”，带有惋惜。

## 讲解

should have done 本应该做却没做；shouldn’t have done 本不该做却做了。

# 强调句

> [!info] 出自 [[01 It is 或 was...that... 强调句]]

## 一句话定义

用 It is/was...that/who... 框架突出句子某一成分的句型，被强调部分放在框架中间。

## 讲解

结构：It is/was + 被强调部分 + that/who + 句子其余部分。is 对应现在，was 对应过去。

强调主语：It was Tom who/that broke the window.（打破窗户的是汤姆。）

强调宾语：It was this book that I bought yesterday.（我昨天买的是这本书。）

强调状语：It was in the park that we met.（我们是在公园里见面的。）

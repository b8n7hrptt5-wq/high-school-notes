# 状语强调

> [!info] 出自 [[01 It is 或 was...that... 强调句]]

## 一句话定义

在 It is/was ... that ... 的强调句型中，被强调成分是时间、地点或原因等状语时，高中语法题通常用 that。注意与带 when、where 等的定语从句区分。

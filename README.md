这套笔记覆盖语文、数学、英语、物理、化学、生物、政治、历史、地理九科，按现行教材逐课整理。库里的 markdown 分两类，别混着数：

| 类型 | 是什么 | 篇数 | 汉字 |
|---|---|---:|---:|
| **课时正文** | 一课一个文件，九板块齐全，成书正文就来自这里 | **716** | 170.3 万 |
| **知识点卡** | 一个概念一张卡，几十字到两三百字，供双链跳转与速查 | **5176** | 112.1 万 |
| 合计 | | 5892 | 282.4 万 |

所以「5892 篇」里只有 716 篇是正文，其余五千多篇都是零散的知识点条目——它们撑起的是双链和附录，不是讲义正文。成书 **48 册 / 3920 页**的正文量对应的是前 716 篇，目录页码、索引指向、题答条数都做过机器校验。

它不是扫描的教辅，也不是把课本抄一遍：每一课都按固定九个板块重写过，把「考什么」和「怎么想」放在前面，把知识点收进附录便于速查。

## 四种用法

**一、只想读 → 打开 `pdf/`**

按学科挑册，A4 尺寸，可直接双面打印或平板上看。每册结构统一：

```
封面 → 这本怎么用 → 目录 → 凡例 → 正文（逐课） → 附录一 知识点速查 → 附录二 知识定位
```

凡例页写明了两类文件的区别：正文是一课九板块的完整讲义，知识点词条只进附录与索引，不当正文读。

**二、想改造 → 用 Obsidian 打开 `notes/`**

克隆后在 Obsidian 里「打开文件夹作为库」，选中 `notes/` 即可。双链、标签、图谱都是原生的，改完能立刻跳转。别忘了先在设置里把「附件默认位置」指向 `附件/`。

**三、想照搭一套 → 看体例**

`notes/` 的目录层级、frontmatter 字段、九板块写法都是固定的，照着自己学科填内容就行，不需要额外的模板引擎。

**四、想每天背 → 导入 Anki**

`pdf/高中笔记.apkg` 是从同一批笔记抽出的问答卡组，**10135 张卡、1300 个卡组**，一卡一问，详见下文「Anki 闪卡」。

## 笔记体例

### 目录即知识树

```
notes/化学/必修第二册/专题07 氮与社会可持续发展/02 第二单元 重要的含氮化工原料/01 氨与铵盐.md
        └科目┘ └──学册──┘ └──────章节──────┘ └────────单元────────┘ └──知识点──┘
```

层级就是教材的层级，文件名保留教材的课序号，所以「专题 7 第二单元第 1 课」这件事在路径里就能读出来，不用打开文件。

同目录下的 `知识点/` 放这一单元的概念卡，正文里 `[[氨气]]` 这样的双链就指向它们。数学有几册是按「章」直接挂课时，没有单元这一层——层级跟着教材走，不强行补齐。

### frontmatter 固定九字段

```yaml
---
科目: 化学
学册: 必修第二册
章节: 专题07 氮与社会可持续发展
单元: 第二单元 重要的含氮化工原料
知识点: 氨与铵盐
日期: 2026-11-23
tags: [化学, 氨气, 铵盐, 铵根检验, 苏教版必修二]
考频: 常考
来源: 苏教版（2019）必修第二册专题7第二单元
---
```

`来源` 一路指回教材的具体册次与单元，方便核对原文；`考频` 分常考、阅读常考、默写常考、写作常考、了解几档，用来决定复习顺序。

### 九板块固定顺序

每一课都用同九个 Callout，位置和顺序不变，翻任何一科都能形成肌肉记忆：

| Callout | 板块 | 作用 |
|---|---|---|
| `[!summary]` | 本节要点 | 一句话结论 + 上/下一课导航 + 本节界限 |
| `[!note]` | 知识点梳理 | 正文主体，概念与规律 |
| `[!abstract]` | 图示理解 | 流程图、关系图、示意图 |
| `[!example]` | 判断与解题流程 | 分步操作，可照着做 |
| `[!important]` | 高考考向与解题技巧 | 这节怎么考、怎么下手 |
| `[!important]` | 必背速查 | 需要背下来的条目 |
| `[!warning]` | 易错辨析 | 典型错法与纠偏 |
| `[!tip]` | 记忆与复习 | 口诀、类比、复习路径 |
| `[!question]` | 练习 | 题目与参考答案 |

716 课时 × 9 个板块，每个板块 716 次，没有一课漏项。

### 双链与标签

`[[氨气]]`、`[[喷泉实验]]` 这类双链共 51895 条，绝大多数落在课时正文里、指向 `知识点/` 下的概念卡。标签体系用于跨册检索（如 `#选必3`、`#语法`、`#纲要上`）。两者分工明确：双链管「这个概念的来龙去脉」，标签管「我要找某一类内容」。

## Anki 闪卡

`pdf/高中笔记.apkg`（2.0 MB）把知识点转成了问答题，导入 Anki 就能按记忆曲线复习。

| 项 | 内容 |
|---|---|
| 卡片 | 10135 张，一卡一问 |
| 卡组 | 1300 个，按 `高中笔记 / 科目 / 册次 / 单元 / 课` 四级嵌套，与笔记目录一一对应 |
| 字段 | `正面`（术语）、`背面`（释义 + 展开说明）、`来源`（指回原笔记） |

| 复习记录 | 无，全新卡组，导入后从零开始排期 |

正面只给一个术语，背面才解释，逼你先回忆再看答案：

> **正面**　不成盐氧化物
>
> **背面**　与酸、与碱都不反应生成盐和水的氧化物，如 CO、NO。

导入方式：桌面版 `文件 → 导入` 选 apkg；手机端把文件传到设备，用 AnkiDroid / AnkiMobile 直接打开即可。

**程序核验——每次重排都跑，结果可复算**

`notes-to-book` 带一个验收脚本 `audit_books.py`，对成品 PDF 逐册跑 13 项检查：

| 项 | 查什么 | 现况 |
|---|---|---|
| C1 | 页数与页码连续 | 48 册通过 |
| C2 | 目录条目是否存在、页码是否落在对应章 | 例：化学必修一 52 条 / 52 命中 |
| C5 · C6 | 每课题数 = 答案条数、题号是否连续 | 全部课时通过 |
| C11 | 索引里每条词条的页码是否指向它**实际出现**的页 | 例：化学必修一 220 条 / 220 命中 |
| C12 | `[[ ]]`、`![[ ]]` 死链残留 | 无 |
| C7 · C8 · C10 | 图块壳残留、化学式上下标、`$…$` 公式残留 | 无 |
| C13 | 单册 ≤ 400 页 | 最大 176 页 |
| C3 · C4 · C9 | 只有标题的页、页尾留白、章标题位置 | C4 有 27 册带警告（板块强制分页的副作用），只算警告不判失败 |

**内容层校验——跑过一次全库，有记录可查**

- 化学方程式配平：658 处逐条核对，0 处配平错误（25 条告警人工复核后全是解析假阳性）
- frontmatter 字段、双链指向、公式残留：全库脚本扫描
- 年代与关键常数、涉港澳台表述：专项核查，逐条改过

**人工逐页复核——9 册**

语文 4 册、数学 5 册做过逐页复核：题号与答案条数逐块核对、文言虚实词与例题对照教材、错字订正。记录在生成器仓库的 `reports/review-语文.md`、`reports/review-数学.md`。

## 勘误与贡献

**一个入口**：本仓库的 [Issues](https://github.com/b8n7hrptt5-wq/high-school-notes/issues/new) 收 PDF、markdown 笔记、Anki 卡包三类问题，不用去生成器仓库重复提。

提的时候请带上：

- **哪一册**（例：化学·必修第一册）
- **印刷页码**（页脚那个数字，不是阅读器里的 PDF 页序；生成器仓库的验收输出按 PDF 页序算，两者差 3–4 页）
- **原文摘录**（照抄一句，能定位）
- **建议改法**（有最好，没有也行）
- 如果是 Anki：卡组名 + 正面术语

直接改 markdown 的 PR 也欢迎，但请注意：目录层级和 frontmatter 字段是生成器依赖的，改动结构会导致页码整体位移，建议先开 Issue 讨论。

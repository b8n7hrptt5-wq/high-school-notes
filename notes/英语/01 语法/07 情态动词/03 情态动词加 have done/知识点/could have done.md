# could have done

> [!info] 出自 [[01 情态动词 + have done 的推测与评价]]

## 一句话定义

可表示过去未实现的可能或机会，也可根据语境推测过去可能发生过的事。例：She could have left already. 意为她可能已经离开。

## 讲解

may、might、could have done 表示过去也许做过，把握较弱。

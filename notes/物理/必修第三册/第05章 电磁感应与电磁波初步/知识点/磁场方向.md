# 磁场方向

> [!info] 出自 [[01 磁场 磁感线 磁感应强度 磁通量]]

## 一句话定义

小磁针静止时 N 极所指方向，即该点磁感应强度方向。

## 讲解

磁体周围存在[[磁场]]，[[磁极]]之间同名相斥、异名相吸。电流周围也存在磁场，电与磁有内在联系。磁场方向规定为小磁针静止时 N 极所指的方向。

[[磁感线]]是形象描绘磁场的曲线：曲线上每一点的切线方向为该点磁场方向，疏密表示磁场强弱。磁感线在磁体外部从 N 极指向 S 极，内部从 S 极回到 N 极，构成闭合曲线，不相交。

判断直线电流、环形电流和通电螺线管的磁场方向用[[安培定则]]（右手螺旋定则）：右手握住导线，大拇指指向电流方向，弯曲四指所指即为磁感线环绕方向。

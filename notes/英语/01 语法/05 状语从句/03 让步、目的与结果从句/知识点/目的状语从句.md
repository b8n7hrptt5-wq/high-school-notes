# 目的状语从句

> [!info] 出自 [[01 让步、目的与结果状语从句]]

## 一句话定义

由 so that、in order that 引导、说明主句动作目的的从句，常含 can、could、may、might。

## 讲解

so that、in order that 为了：He spoke loudly so that everyone could hear him.

从句常含 can、could、may、might、will、would 等情态动词。

in order that 可置于句首，so that 一般在主句之后。

# 熟词生义

> [!info] 出自 [[04 词义猜测与代词指代]]

## 一句话定义

常见词在具体语境中的临时引申义，不适用词典常用义。

## 讲解

熟词生义指常见词在具体语境中的引申义。判断时把常用义代入句子看是否通顺，不通顺则按并列或对比线索另推。例如 run 在不同语境中可表示运转、流动、管理；词义必须服从句子语境，不服从词表记忆。
